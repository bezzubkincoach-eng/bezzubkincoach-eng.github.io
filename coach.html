Ссылка для клиента

Для тренера. Клиенту ничего настраивать не нужно — он просто открывает ссылку.

  1. Открой шаблон таблицы → Файл → Создать копию, назови по имени клиента.
  2. В копии нажми Настройки доступа → «Все, у кого есть ссылка» → Читатель.
  3. Скопируй адрес таблицы из браузера и вставь сюда ↓
Это не похоже на ссылку Google-таблицы.
